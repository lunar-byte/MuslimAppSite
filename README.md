# Waqti.app — Лендинг мобильного приложения

Лендинг для мобильного приложения **Waqti.app** — приложения для мусульман без рекламы, содержащего только самые важные функции. Готов к деплою на Vercel.

## Особенности

- Минималистичный дизайн с использованием зеленого цвета (#2E7D32)
- Header с навигацией
- Hero блок с формой сбора email для раннего доступа
- Адаптивная верстка
- Чистый код без градиентов

## Структура проекта

```
├── pages/
│   ├── _app.js          # Корневой компонент приложения
│   └── index.js         # Главная страница (header + hero + footer)
├── styles/
│   └── global.css       # Глобальные стили
├── package.json         # Зависимости проекта
├── next.config.js       # Конфигурация Next.js
└── vercel.json          # Конфигурация Vercel
```

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 в браузере.

## Деплой на Vercel

1. Установите Vercel CLI: `npm i -g vercel`
2. Запустите: `vercel --prod`

Или подключите репозиторий к Vercel для автоматического деплоя.

## Настройка домена

1. Добавьте домен в Vercel Dashboard (Settings → Domains)
2. В Reg.ru добавьте DNS-записи, которые предоставляет Vercel:
   - A-запись для корневого домена (например, `@ → 76.76.21.21`)
   - CNAME для www (например, `www → cname.vercel-dns.com`)
3. Подтвердите домен в Vercel
