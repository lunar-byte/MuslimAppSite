# Sabr PWA — план сборки для Claude Code

## Правила работы
- Каждый этап заканчивается проверкой в браузере
- Следующий этап начинается только после подтверждения «работает»
- Стили берём из `style.md`
- Данные сессии храним в `localStorage`

---

## Этап 0 — Каркас проекта

**Задача:** поднять пустое приложение, убедиться что Vite, роутинг и PWA работают.

```
Создай Vite + React проект со следующей структурой:

/public
  manifest.json (пустой, заглушка)
  icon-192.png (любой placeholder)
  icon-512.png (любой placeholder)
  icon-apple-180.png (любой placeholder)

/src
  main.jsx        — BrowserRouter + Routes
  App.jsx         — пустой layout-обёртка
  pages/
    SabrIntro.jsx     — текст "Intro"
    Step1.jsx         — текст "Step 1"
    Step2.jsx         — текст "Step 2"
    Step3.jsx         — текст "Step 3"
    Step4.jsx         — текст "Step 4"
    Step5.jsx         — текст "Step 5"
    Step6.jsx         — текст "Step 6"
    SabrComplete.jsx  — текст "Complete"

vite.config.js    — с VitePWA плагином
vercel.json       — rewrite /* → index.html
index.html        — с iOS meta тегами
```

Маршруты:
- `/` → SabrIntro
- `/step/1` → Step1
- `/step/2` → Step2
- `/step/3` → Step3
- `/step/4` → Step4
- `/step/5` → Step5
- `/step/6` → Step6
- `/complete` → SabrComplete

**Проверка:**
- `npm run dev` запускается без ошибок
- Переход по `/step/3` вручную в адресной строке работает
- В DevTools → Application → Manifest — данные подтягиваются
- В DevTools → Application → Service Workers — зарегистрирован

## Этап 1 — Навигация и прогресс

**Задача:** переходы между шагами, прогресс-бар, кнопки «Далее» / «Назад».

```
Реализуй навигацию между шагами:

1. Компонент ProgressBar
   - принимает props: currentStep (1–6), totalSteps (6)
   - отображает 6 точек/полосок, закрашивает пройденные

2. Компонент StepLayout
   - обёртка для всех Step-страниц
   - содержит: ProgressBar вверху, slot для контента, кнопки внизу
   - кнопка «Далее» → navigate('/step/N+1')
   - кнопка «Назад» → navigate(-1)
   - на Step6 кнопка «Далее» → navigate('/complete')

3. SabrIntro
   - кнопка «Начать практику» → navigate('/step/1')

4. Оберни все Step1–Step6 в StepLayout
```

**Проверка:**
- Клик «Начать» переходит на Step 1
- «Далее» последовательно проходит все 6 шагов
- «Назад» возвращает на предыдущий шаг
- Прогресс-бар обновляется на каждом шаге
- На Step 1 кнопка «Назад» ведёт на Intro (или скрыта)

## Этап 2 — Хранилище сессии

**Задача:** единый стейт сессии, сохранение в localStorage.

```
Создай src/hooks/useSabrSession.js

Хук возвращает:
- session — объект текущей сессии
- updateStep(stepNumber, data) — обновить данные шага
- clearSession() — очистить сессию

Структура session:
{
  createdAt: ISO-строка,
  step1: { trigger: '', emotions: [] },
  step2: { negativeThoughts: '', whoBecome: '', thoughtsTruth: null },
  step3: { alternatives: [], gratitude: ['','','','',''] },
  step4: { allahName: '', nameIntention: '' },
  step5: { healthyThought: '', niyyah: '', oneStep: '' },
  step6: { rerating: [], finalNote: '' }
}

Сохранять в localStorage по ключу 'sabr_session' после каждого updateStep.
При инициализации — читать из localStorage если есть.
```

**Проверка:**
- Вызов `updateStep(1, { trigger: 'тест' })` сохраняется в localStorage
- После перезагрузки страницы данные не теряются
- `clearSession()` очищает localStorage и сбрасывает стейт

## Этап 3 — Step 1: Эмоции

**Задача:** первый реальный экран — триггер, эмоции, интенсивность.

```
Реализуй Step1.jsx:

1. Поле «Что произошло?»
   - textarea, сохраняет в session.step1.trigger

2. Список эмоций (чекбоксы / тапабельные чипы)
   Список: Подавлен, Грустно, Испуган, Злость, Обижен, Разочарован,
           Тревога, Онемение, Беспомощность, Растерян
   - мультивыбор
   - сохраняет в session.step1.emotions как массив { name, intensity: 5 }

3. Для каждой выбранной эмоции — слайдер интенсивности 1–10
   - подпись «1 = слабо, 10 = очень сильно»
   - обновляет intensity в массиве emotions

4. Кнопка «Далее» активна только если:
   - trigger не пустой
   - выбрана хотя бы одна эмоция
```

**Проверка:**
- Выбор эмоции показывает слайдер под ней
- Снятие чекбокса убирает слайдер и удаляет из массива
- После нажатия «Далее» и возврата назад — данные сохранены
- В localStorage виден объект step1 с заполненными данными

## Этап 4 — Step 2: История за эмоцией

```
Реализуй Step2.jsx:

1. Textarea «Негативные мысли в голове»
   → session.step2.negativeThoughts

2. Textarea «Кем я становлюсь с этими мыслями?»
   → session.step2.whoBecome

3. Три кнопки-выбора: «Да» / «Может быть» / «Нет»
   Вопрос: «Эти мысли всегда правда?»
   → session.step2.thoughtsTruth ('yes' | 'maybe' | 'no')
   Одна кнопка активна за раз.
```

**Проверка:**
- Кнопки переключаются (только одна активна)
- Все три поля сохраняются в сессии

## Этап 5 — Step 3: Расширь сердце

```
Реализуй Step3.jsx:

1. Чекбоксы «Другие объяснения» (мультивыбор):
   - «Это может быть не так плохо, как кажется»
   - «Их намерение могло быть не плохим»
   - «Они могут сами через что-то проходить»
   - «У меня нет всей картины»
   - «Это не личное»
   - «Возможно, Аллах защищает меня»
   → session.step3.alternatives (массив строк-ключей)

2. Пять полей благодарности
   Заголовок: «5 перспектив благодарности»
   Нумерованные textarea (1–5)
   → session.step3.gratitude (массив из 5 строк)

3. Блок мухасаба «Что нужно очистить в сердце?»
   Чекбоксы: Предположения, Гордость, Обиду, Нетерпение, Резкость, Зависть
   → session.step3.muhasaba (массив строк)
```

**Проверка:**
- Чекбоксы и поля сохраняются
- Кнопка «Далее» доступна без обязательных полей (шаг не блокирующий)

```

3. При выборе — показать карточку с арабским написанием и значением

4. Textarea «В честь этого Имени я...»
```

**Проверка:**

## Этап 8 — Step 6: Завершение

```
Реализуй Step6.jsx:

1. Блок повторной оценки
   Для каждой эмоции из session.step1.emotions показать:
   - Название эмоции
   - Исходная оценка (было: N) — только отображение
   - Слайдер новой оценки 1–10 (стало: M)
   → session.step6.rerating (массив { name, before, after })

2. Textarea «Заметка себе»
   → session.step6.finalNote

3. Кнопка «Завершить практику» → navigate('/complete')
   При нажатии: добавить completedAt: ISO-строка в сессию
```

**Проверка:**
- Отображаются только эмоции, выбранные на Step 1
- Исходные оценки совпадают с введёнными на Step 1
- После нажатия «Завершить» — переход на /complete

## Этап 9 — Complete: Итог сессии

```
Реализуй SabrComplete.jsx:

1. Заголовок «Практика завершена»

2. Краткое резюме сессии:
   - Триггер (из step1.trigger)
   - Эмоции с динамикой: «Подавлен: 7 → 3»
   - Выбранное Имя Аллаха
   - Намерение (ниет)
   - Один шаг

3. Кнопка «Новая практика»
   - вызывает clearSession()
   - navigate('/')

4. Кнопка «История практик» (заглушка, navigate('/history'))
   — реализуем в следующем этапе
```

**Проверка:**
- Данные из сессии корректно отображаются
- «Новая практика» очищает localStorage и уходит на Intro

## Этап 10 — История практик (опционально)

```
Создай src/pages/History.jsx

При завершении практики (Этап 8) — сохранять сессию в массив:
localStorage.getItem('sabr_history') → массив сессий

History.jsx:
- Список завершённых практик, отсортированный по дате
- Для каждой: дата, триггер, главная эмоция + динамика
- Тап по записи → развернуть полное резюме
- Кнопка удаления записи
```
